# Deployment Streamlit

Dashboard saat ini dapat dijalankan secara lokal. Pada tahap integrasi, gunakan repository ini sebagai sumber untuk Streamlit Community Cloud.

1. Buka [Streamlit Community Cloud](https://share.streamlit.io/) dan hubungkan akun GitHub yang memiliki akses ke repository.
2. Buat aplikasi dari branch `main` dengan entry point `app.py`. Pilih Python 3.12.
3. Setelah aplikasi selesai dibangun, buka URL Streamlit di jendela privat dan periksa akses, pemuatan dataset, serta navigasi dashboard.
4. Catat URL yang sudah diuji di `project.json` dan README.

Daftar dependensi ada di `requirements.txt`. Dataset AI4I diunduh dari UCI saat pertama kali dimuat. Untuk cara menjalankan secara lokal, lihat [README](README.md#menjalankan-dashboard).
